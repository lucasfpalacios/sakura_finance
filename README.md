## 🇬🇧 English

**Sakura Finance** is a full-stack personal finance management application designed to help users track their debts, transactions, and investments cleanly and efficiently. 

This project is separated into a robust Python-based API and a modern web frontend, both deployed in the cloud.

### ✨ Features
* **Transaction Tracking:** Easily log daily incomes and expenses.
* **Debt Management:** Keep a clear record of active debts and their statuses.
* **Investment Dashboard:** Monitor your investment portfolio.
* **Cloud Ready:** Fully configured for deployment on Render (Backend) and Vercel (Frontend).

### 🛠️ Tech Stack
* **Frontend:** [Next.js](https://nextjs.org/) / React
* **Backend:** Python / [FastAPI](https://fastapi.tiangolo.com/) (uvicorn)
* **Database:** MongoDB
* **Deployment:** Vercel (Frontend) & Render (Backend)
